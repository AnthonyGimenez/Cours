# Two option to go in the website :

- First you can go in the URL : `https://anthonygimenez.github.io/Cours`
- Or dowload it, and launch it.

If you launch it, you will need `NodeJS` to launch the app.

# Installation

If you really want to use it, you can clone it :

```bash
git clone https://github.com/AnthonyGimenez/Cours
```

After dowloaded it, you can do the installation by `npm install`

# Launch the website

You can launch the website with `npm start`

- You can had `--host` to change the host (`--host 0.0.0.0` will be on all your interface network).
- You can had also `--port` to change the port of the website.
